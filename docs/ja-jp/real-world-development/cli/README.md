**[GitHub Copilot CLI][about-copilot-cli]** を使うと、ターミナルで GitHub Copilot をエージェント型のコーディングアシスタントとして利用できます。コードベースを調べ、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンドラインから行えるため、グラフィカルエディターに切り替えずに作業の流れを保てます。

このワークショップでは、Tailspin Toys の一連のワークフローに取り組みます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、基本操作を確認します。
2. 星評価の変更を加え、ブラウザーでレビューし、最初のプルリクエスト（PR）を手動でマージします。
3. フィルタリングの issue から始め、Plan モードで方針を定め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新して、フィルタリングの作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol（MCP）サーバーを追加し、ブラウザーでフィルタリングの動作を確認します。
7. 品質保証（QA）カスタムエージェントを作成し、要件、カバレッジ、検証の証拠をレビューします。
8. フィルタリングの変更全体をレビューし、フィルタリングの PR に Agent Merge を使用します。
9. コンテキスト、モデル、共有、任意のクラウド委任に役立つスラッシュコマンドを確認します。

ワークショップでは、PR を 2 つ作成します。1 つ目は星評価、2 つ目は指示の更新、スキルの更新、QA プロファイル、テストを含むフィルタリングです。フィルタリングと品質に関する作業では、1 つの会話とブランチを共有するため、各ツールを学びながら作業を積み重ねられます。

## 前提条件

このワークショップに参加する前に、次を準備してください。

- [ ] **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかの有効なプランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランを利用していない場合、認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合は、管理者が Copilot CLI を有効にしていることを確認してください。
