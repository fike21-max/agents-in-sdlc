Copilot CLI をインストールして会話を試したので、次はプロジェクトに初めて変更を加えましょう。変更は小さく保ちます。ゲームデータにはすでに星評価がありますが、ホームページのゲームカードには表示されていません。エージェントに評価を表示するよう依頼し、変更を確認して、最初のプルリクエストとしてマージします。

このレッスンでは、次のことを行います。

- 機能ブランチで、対象を絞った Copilot との会話を開始します。
- エージェントに小さな変更を依頼します。
- `/diff` で変更を確認します。
- アプリを実行し、転送したブラウザーで変更を確認します。
- 最初のプルリクエストを作成してマージします。

## シナリオ

Tailspin Toys の各ゲームには星評価があり、ゲーム詳細ページにはすでに表示されています。一方、ホームページのゲームカードにはタイトル、カテゴリ、発行者、説明しか表示されていません。最初の練習として、各カードに既存の評価を表示するようエージェントに依頼します。最初のセッションに最適な、小さく独立した変更です。

## 会話の基本

**会話**とは、Copilot CLI でタスクに取り組む場です。Copilot app とは異なり、通常の CLI 会話では、ターミナルで現在チェックアウトしているリポジトリと Git ブランチを使います。保存した会話に戻ることはできますが、ファイルとブランチはディスク上の通常の Git 状態のままです。

会話には、プロンプトとエージェントの応答、ファイルを調査・編集するエージェントのツール操作、`/diff` で確認できる変更の 3 つが表示されます。

## 会話を開始して変更を依頼する

機能の実装を始めるため、新しい会話を開始します。

1. Codespace に戻ります。
2. 前回のターミナルが開いていない場合は、<kbd>Control</kbd>+<kbd>\`</kbd>（Mac）または <kbd>Ctrl</kbd>+<kbd>\`</kbd>（Windows/Linux）を押します。
3. まだ起動していない場合は、次のコマンドで Copilot を起動します。

   ```bash
   copilot --yolo
   ```

4. スラッシュコマンド `/new` を実行して新しいセッションを開始し、<kbd>Enter</kbd> を押します。
5. 次のプロンプトで変更を依頼します。

   ```plaintext
   一覧ページのゲームカードに、各ゲームの `starRating` を 5 点満点で表示してください。評価が `null` の場合は「評価はまだありません」と表示してください。カードのレイアウトは変更せず、テストを追加して、関連するチェックを実行してください。
   ```

Copilot はプロジェクトを調べ、ゲーム詳細を表示するファイルを特定し、必要なコードを作成します。これで Copilot CLI を使った新機能の追加ができました。

## 差分をレビューする

小さな変更でも、AI が生成した変更はすべてマージ前にレビューする必要があります。Copilot CLI で変更を確認しましょう。

1. `/diff` を入力して、変更されたすべてのファイルを確認します。
2. ゲームカードに評価がある場合は数値が表示され、`starRating` が `null` の場合は `No rating yet` と表示されることを確認します。
3. テストが両方の状態をカバーしていることを確認します。
4. Copilot が実行したチェックの結果を確認し、失敗があれば修正を依頼します。
5. レビューが終わったら、<kbd>Esc</kbd> を押して差分画面を閉じます。

> [!NOTE]
> Copilot を含むすべての生成 AI ツールは、決定的ではなく確率的に動作するため、実際のコードはここに示した内容と異なる場合があります。特定の実装ではなく、動作を確認してください。

## 変更を確認する

コードを読むだけで、動作すると判断するべきではありません。Copilot にウェブサイトを起動してもらい、Codespaces で転送したブラウザーから更新後の UI を確認します。

1. Copilot にアプリの起動を依頼します。

   ```plaintext
   アプリを起動して、ブラウザーで星評価の変更を確認できるようにしてください。URL を教え、サーバーは起動したままにしてください。
   ```

2. Codespaces でポート `4321` が利用可能と表示されたら、**Open in Browser** を選択します。
3. ゲームカードに 5 点満点の評価が表示されることを確認します。
4. Copilot に戻り、起動したサーバーを停止するよう依頼します。

   ```plaintext
   起動した開発サーバーを停止してください。
   ```

## 最初のプルリクエストを作成してマージする

機能を作成できました。次は、プロジェクトにコードをマージするためのプルリクエスト（PR）を作成します。

1. 既定のエージェントに変更のコミットを依頼します。

   ```plaintext
   レビュー済みの星評価の変更を、適切なコミットメッセージでコミットしてください。
   ```

2. `/pr create` を実行します。Copilot CLI は PR の作成時に既存のコミットをプッシュし、PR の URL を表示します。
3. Copilot CLI に表示された URL を、<kbd>Command</kbd>（Mac）または <kbd>Ctrl</kbd>（Windows/Linux）を押しながら選択して、PR を開きます。
4. 変更されたファイルとチェックをレビューします。
5. 問題がなければ、**Merge pull request** を選択し、マージを確定します。
6. Codespace に戻り、`/exit` で Copilot CLI を終了します。
7. ローカルの `main` を更新します。

   ```bash
   git checkout main
   git pull
   ```

## まとめと次のステップ

おめでとうございます。GitHub Copilot CLI を使って、初めての変更をリリースしました。具体的には、次のことを行いました。

- 機能ブランチで対象を絞った Copilot との会話を開始しました。
- ゲームカードへの小さな変更をエージェントに依頼しました。
- `/diff` で変更をレビューしました。
- アプリを実行し、転送したブラウザーで星評価を確認しました。
- 最初のプルリクエストを作成してマージしました。
