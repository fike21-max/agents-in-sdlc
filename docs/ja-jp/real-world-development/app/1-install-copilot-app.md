**[GitHub Copilot app][about-copilot-app]** は、エージェント主導の開発に使うデスクトップアプリケーションです。GitHub Copilot CLI を基盤とし、GitHub とネイティブに統合されているため、リポジトリ、ブランチ、CI パイプラインをすぐに利用できます。自分だけですべての作業を行うのではなく、複数のエージェントをそれぞれ分離されたワークスペースで並行して指示し、反復作業を自動化するワークフロー向けに設計されています。Node.js をインストールし、プロジェクトのコピーを準備できたので、次はアプリをインストールしてリポジトリを接続します。

このレッスンでは、次のことを行います。

- GitHub Copilot app をインストールしてサインインします。
- GitHub リポジトリからプロジェクトをアプリに追加します。
- テンプレートによって用意されたバックログを含め、ワークスペースを確認します。
- クイックチャットを試して、アプリ自体について質問します。

## シナリオ

チームは、増え続けるバックログに対応するために AI エージェントを導入しています。Copilot app では、issue の選択、エージェントの実行、変更のレビュー、プルリクエストのマージを一か所から指示できます。このレッスンでは、アプリをインストールして接続し、プロジェクトについて会話を始められるようにします。

> [!NOTE]
> 対象となる Copilot プランが必要です。Copilot Free、Copilot Student、またはいずれかの有料プラン（Pro、Pro+、Business、Enterprise）を利用してください。Copilot Business または Copilot Enterprise を使用している場合、管理者は **GitHub Copilot app** ポリシーを有効にしておく必要があります。

## GitHub Copilot app をインストールして構成する

GitHub Copilot app を使用するには、まずアプリをインストールします。Windows、macOS、Linux 向けのバージョンがあります。アプリをインストールして認証し、Tailspin Toys リポジトリを追加しましょう。

1. ブラウザーで [GitHub Copilot app のランディングページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ページに記載された手順に従ってインストールします。
3. インストールが完了したら、アプリを開きます。
4. **Sign in to GitHub** を選択し、画面の指示に従って認証します。データレジデンシーが有効な GitHub Enterprise Cloud を使用する場合は、**Use GitHub Enterprise** を選択し、求められたら `*.ghe.com` のホスト名を入力します。GitHub Enterprise Server はサポートされていません。
5. オンボーディングでリポジトリの選択を求められたら、テンプレートから作成した Tailspin Toys リポジトリを選択します。リポジトリの選択をスキップし、オンボーディング後にプロジェクトを追加することもできます。
6. テーマを選択するよう求められたら選択し、オンボーディングを完了します。
7. サイドバーの **Sessions** にリポジトリがあるか確認します。すでに表示されている場合、再度追加する必要はありません。
8. まだ接続されていない場合は、**Sessions** の横にある **+** を選択して新しいセッションを作成し、**Add GitHub repository** を選択します。前提条件のレッスンで控えた所有者名とリポジトリ名を入力します。
9. リポジトリがサイドバーに表示されることを確認します。ここで使用するレイアウトでは、`tailspin-toys` などのリポジトリフォルダーが **Sessions** の下にまとまり、その下に個々のセッションが表示されます。

## ワークスペースを確認する

プロジェクトを接続したら、アプリの使い方を確認しましょう。サイドバーには、主に次の領域があります。

- **New** - ここから Copilot との新しいチャットセッションを開始できます。
- **Pull requests** - アプリの GitHub ネイティブ統合を通じてプルリクエストを表示します。アプリを離れずに、プルリクエストを参照・絞り込み、CI の状態を確認し、レビューできます。
- **Issues** - 同じように issue を表示します。issue を参照・絞り込み、issue からセッションを開始できます。
- **Automations** - スケジュールまたはオンデマンドで実行する、保存済みのエージェントタスクです。To Do リストの管理、定期的なプロジェクト保守、その他の面倒な作業を任せられます。振り返りでは次のステップとして紹介しますが、追加の演習ではありません。
- **Customize** - MCP サーバー、プラグイン、スキルなどのコンポーネントを追加して、Copilot app の機能を拡張します。後のレッスンで Playwright MCP の設定に使います。
- **Chats** - 専用のブランチやワークスペースを必要としない、質問やブレインストーミング向けの軽い会話です。最初のチャットを開始すると、この領域が表示されます。表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始してください。
- **Sessions** - リポジトリのフォルダーと、そのエージェントセッションをまとめます。`tailspin-toys` などのリポジトリ名を選ぶとリポジトリビューが開き、その下のセッションを選ぶと会話に戻ります。各セッションは独自の分離されたワークスペースで実行されるため、変更を競合させずに複数のセッションを同時に実行できます。星評価を追加するときに、最初のセッションを開始します。

ワークショップを進めながら、各領域を使っていきます。

> [!TIP]
> 操作方法がわからない場合や、実行できるかどうか知りたい場合は、Copilot に尋ねてみましょう。手順を案内してくれます。

### 用意されたバックログを確認する

バックログのないプロジェクトはほとんどなく、Tailspin Toys も例外ではありません。テンプレートからリポジトリを作成したときに用意されたバックログを確認しましょう。

1. サイドバーの **Sessions** で、個々のセッションではなく Tailspin Toys のリポジトリフォルダーを選択します。次に、リポジトリの上部ナビゲーションで **Issues** を選択します。
2. issue 番号を決めつけず、次のタイトルで探します。

   - Allow users to filter games by category and publisher
   - Update our repository coding standards

3. issue を選択して詳細を読みます。各 issue からエージェントセッションを開始することもできます。最初の変更を終えた後、フィルタリングの issue から作業を始めます。

> [!NOTE]
> **Issues** と **Pull requests** の一覧は、Copilot app に追加したリポジトリの項目だけが表示されるよう自動的に絞り込まれます。ほかのリポジトリの作業項目を表示するには、そのリポジトリをアプリに追加してください。

## クイックチャットを試す

アプリに慣れるには、アプリ自体について質問するのが効果的です。その用途には **クイックチャット** が適しています。クイックチャットでは、ブランチや worktree を作らずに質問やブレインストーミングができます。セッションを必要としない、すぐに終わる質問に最適です。

1. サイドバーで **Chats** の横にある **+** を選択し、新しいチャットを開きます。**Chats** がまだ表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始します。開始後に **Chats** が表示されます。
2. アプリのセッションの仕組みを尋ねます。

   ```plaintext
   How does the GitHub Copilot app use worktrees?
   ```

3. 会話ビューで回答を読みます。各セッションが独自の分離された git worktree で実行されるため、変更を競合させずに複数のエージェントを並行して実行できることがわかります。会話はそのまま続けることも、いつでも新しいチャットを開始することもできます。

## まとめと次のステップ

GitHub Copilot app をインストールし、プロジェクトを接続して、ワークスペースを確認しました。次のことを行いました。

- アプリをインストールして GitHub にサインインしました。
- GitHub リポジトリからプロジェクトを追加しました。
- ワークスペースを確認し、**Issues** で用意されたバックログを見つけました。
- クイックチャットで、すぐに終わる質問をしました。

次は、[最初のエージェントセッションを開始し][next-lesson]、ゲームカードに星評価を表示します。
